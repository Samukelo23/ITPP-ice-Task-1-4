## Before you publish

1. **Photo** — `index.html` currently uses a placeholder image. Replace the `src` on the `.hero-photo` image with a real photo of yourself (add the image file to this folder and point to it, e.g. `src="photo.jpg"`).
2. **Second project** — `projects.html` has one placeholder project. Replace the title, description, tools, screenshot, and link with a real second project.
3. **Personalise the drafts** — `about.html` and `reflection.html` are first-draft text written on your behalf. Read them over and rewrite anything that doesn't sound like you, especially the reflection's "strongest skill" and "skill to improve" sections.
4. **Check both links** — confirm the GitHub and LinkedIn links in the footer go where you expect.

## Publish with GitHub Pages

1. Create a new GitHub repository (or use an existing one).
2. Add these files to the repository's root (or to a `/docs` folder, if you'd rather keep it separate from other code).
3. In the repo, go to **Settings → Pages**.
4. Under **Source**, choose the branch (usually `main`) and the folder (`/root` or `/docs`, matching where you put the files).
5. Save. GitHub will give you a URL like `https://yourusername.github.io/your-repo-name/` within a minute or two.
6. Open that link in a private/incognito window to confirm it works without you being logged in — that's what your lecturer will see.
